Privacy Policy

App: Attachment Policy Guard for Jira

Last updated: 3 October 2026

1. What this app does with data

The app runs inside your Atlassian Cloud site on the Atlassian Forge platform. When a file is attached to a work item in a project where your policy is on, Jira notifies the app and the app processes:

  • attachment details: attachment ID, file name, size, MIME type, project ID, work item ID and key, and the Atlassian account ID of the person who uploaded it;
  • the first 4 KB of the file, read in memory to identify the real file type (for example, an executable renamed to .pdf). File contents are never stored.
  • the policy settings a Jira administrator saves, and the Atlassian account ID of the administrator who last saved them.

When an administrator uses Test a file on the settings page, the browser sends the first 4 KB of the chosen local file to the app so it can show the result. That data is not stored and is not uploaded to Jira.

The app does not read descriptions, comments or other work item fields. It looks up a work item only to show its key in the audit log.

2. What the app changes on your site

In report mode (the default after installation) the app changes nothing; it only records policy matches. In enforce mode the app removes attachments that break the policy and, if you choose, adds a note to the work item. Removed attachments are deleted by Jira; the app keeps no copy.

3. Where data is stored

All processing and storage happen on Atlassian's Forge platform, inside Atlassian's cloud infrastructure. The app has no servers of its own and sends no data to Atesen Software or to any third party. It makes no outbound network calls. There are no analytics services, no advertising networks, no AI services and no sub-processors.

4. How long data is kept

Uninstalling the app removes the app's storage according to Atlassian's Forge data retention policies.

5. Logs

The app writes application logs for troubleshooting. These logs contain the event type, the decision (allowed or blocked), the action taken and error types. They never contain file names, account IDs, work item keys or note text. Forge logs are stored by Atlassian and are visible to the publisher only through Atlassian's developer tooling, with Atlassian's own retention limits.

6. Roles

For the data processed by this app, your organization is the controller. Atesen Software acts as a processor to the limited extent the app runs on your site. Atlassian is the infrastructure provider; see Atlassian's own privacy policy for how they process data in your cloud site.

7. Your requests

To ask about data handled by this app, or to request deletion of app data on your site, write to sametatesen2@gmail.com.

8. Security

The app requests only the Atlassian scopes it needs: reading work items and attachments, removing attachments and adding notes, and app storage. The settings page is a Jira administration page, visible only to Jira administrators.

9. Changes

Material changes to this policy are announced in the app's release notes on the Atlassian Marketplace listing.
